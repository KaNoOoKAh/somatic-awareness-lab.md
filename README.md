# somatic-awareness-lab.md

A centralized repository for somatic awareness research, field notes, trial logs, and supporting reference material migrated from `KaNoOoKAh/somatic-cognitive-anomalies`.

## Repository structure

- `field-notes/` — observational logs, environmental notes, and media guidance
- `notes/` — administrative notes and movement-specific notes
- `policies/` — editing and document handling guidance
- `research/` — topic-based research collections
- `theories/` — theory documents, field logs, and technical appendices
- `trials/` — trial records
- `archive/` — preserved legacy documents that did not fit the primary structure cleanly
