# Documentation (`/docs`)

This directory contains the foundational research, domain knowledge, and reference materials for the somatophysical project. Use this space to log what you learn as you build the system.

## Folder Contents
* **research/** – Academic papers, medical articles, and reference links regarding somatophysical data.
* **specifications/** – Technical requirements, data schemas, and sensor hardware guides.
* **guides/** – Internal notes, tutorials, and setup instructions for contributors.

## Learning Objectives
* [ ] Understand core somatic and physiological metrics.
* [ ] Define data formats for body-tracking variables.
* [ ] Map out the software architecture.
