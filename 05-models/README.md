# 05 — Models

Computational and theoretical models for somatophysical integration.

## What Goes Here

- Mathematical or computational models of somatic processes
- Trained machine-learning or statistical models (with version notes)
- Model evaluation reports and comparison tables
- Architecture diagrams and explanatory write-ups

## Structure

```
05-models/
  model-name/
    README.md      ← description, inputs/outputs, performance
    src/           ← model code
    checkpoints/   ← saved model weights or parameters
    results/       ← evaluation outputs
```
